Preview:
Open index.html in your web browser. The Manhattan-inspired financial-district building photo is loaded from Unsplash, so an internet connection is needed for the photo. A dark gradient appears if the photo is unavailable.

Publishing to GitHub Pages:
1. Create a NEW public repository for Cross World (separate from The Couton Foundation).
2. Upload the extracted index.html file to the root of the new repository. Do not upload only the ZIP.
3. Go to Settings > Pages and select Deploy from a branch, main, /(root).
4. GitHub will provide a free github.io website URL. Add a custom domain later if desired.
